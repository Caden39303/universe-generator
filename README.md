# Null Rift

A deterministic procedural universe explorer built with only vanilla HTML, CSS, JavaScript, and Canvas. Open `index.html` directly in a browser—there is no Node.js, npm, framework, or build step.

## Features

- Seed-stable galaxies, systems, planets, names, civilizations, events, resources, and lore.
- Canvas universe → galaxy → system → dedicated planet exploration mode.
- Breadcrumb navigation back up the hierarchy.
- Planet visualization with atmosphere glow, terrain bands, moons, and detail data.
- Mouse-wheel zooming, pointer-centered zoom, dragging/panning, and click navigation.
- Correct devicePixelRatio handling: the backing canvas uses physical pixels while drawing and pointer coordinates remain in CSS pixels.

## Run

Open `index.html` in any modern browser. Use the same seed to reproduce the same universe.
